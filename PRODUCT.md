# FinanceAI Product Context

## Users
FinanceAI is a single-user personal finance and life dashboard. The primary user checks money, transactions, goals, agenda, notes, and routines across phones, tablets, laptops, and desktops.

## Purpose
Help one person understand their current financial position and day-to-day commitments quickly, then record changes with very little friction.

## Primary jobs
- See net worth, wallet balances, income, expenses, and savings at a glance.
- Record income, expense, and wallet transfers quickly.
- Review recent transactions and financial goals.
- Check upcoming agenda items.
- Keep personal notes and local backups.

## Platform
Web PWA with adaptive responsive layouts. Mobile and desktop are both first-class experiences.

## Product constraints
- Personal and single-user. No family/group/member/approval concepts.
- Finance is the primary domain; life-management modules are secondary.
- Local-first and offline-friendly.
- Data is private by default.
- Core application must remain provider-agnostic and deployment-portable.
- The UI must work with touch, mouse, trackpad, and keyboard.

## Evidence on hand
- PRD in `docs/PRD.md`.
- Existing runnable Next.js product UI and domain models.
- No user research, brand study, or production analytics yet.

## Terminology
Use: Dashboard, Finance, Wallet, Transaction, Goal, Calendar, Personal, Note.
Avoid family/group terminology unless product scope changes explicitly.
