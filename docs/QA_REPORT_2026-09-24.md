# FinanceAI QA Report — 24 September 2026

## Scope

Audit dilakukan terhadap source `FinanceAI-PRD-Complete.zip`: PRD alignment, static quality, business calculations, import validation, PWA assets/service worker, responsive CSS, CI contract, dan Vercel deployment contract.

## Passed in the audit sandbox

- PRD contract tests: 7/7 pass.
- Structural TypeScript check terhadap seluruh `src/**/*.ts(x)`: pass menggunakan compiler TypeScript yang tersedia di sandbox dengan framework type stubs karena dependency registry tidak dapat dijangkau.
- Runtime assertions untuk wallet transfer, finance summary, cashflow, category spending: pass.
- Runtime assertions untuk import validator, duplicate entity IDs, dan wallet type `other`: pass.
- CSS parser check: pass.
- `public/sw.js` JavaScript syntax check: pass.
- Manifest JSON parse dan installability contract: pass.
- PWA icon dimensions: 192x192 dan 512x512, keduanya valid PNG.
- Static HTTP check: manifest dan offline fallback mengembalikan HTTP 200; manifest disajikan sebagai `application/manifest+json`.
- Source scan tidak menemukan credential/API secret yang tertanam di source.

## Fixes applied

- Menghilangkan render-time clock reads pada dashboard/finance/calendar/quick-add yang berisiko melanggar React purity rules.
- Mengubah online status menjadi `useSyncExternalStore` dan memperkuat offline navigation ke document-cache path.
- Menghapus synchronous theme state hydration effect; icon theme sekarang mengikuti root theme state via CSS.
- Memperbaiki local-date conversion agenda agar tidak bergeser karena UTC.
- Menolak end time agenda yang tidak sesudah start time.
- Memperbaiki internal error-page navigation memakai Next `Link`.
- Menambahkan wallet type `Other` sesuai PRD.
- Menampilkan nama wallet pada recent transactions dashboard sesuai minimum data PRD.
- Memperketat JSON import agar duplicate ID ditolak pada semua entity, bukan wallet saja.
- Memperkuat service-worker runtime cache dengan `event.waitUntil` dan hanya menyimpan response sukses.
- Memperbaiki CI agar tidak mengaktifkan npm dependency cache ketika source belum memiliki lockfile.
- Memperluas PRD contract tests dari 4 menjadi 7 test cases.

## Environment limitation

Sandbox audit tidak memiliki outbound network ke npm registry. `registry.npmjs.org` gagal di-resolve dan direct-IP HTTPS juga diblokir. Karena ZIP tidak menyertakan `node_modules` atau lockfile/cache dependencies, full dependency installation tidak dapat diselesaikan di environment ini.

Akibatnya, tiga verifikasi yang membutuhkan runtime Next.js asli belum dapat diklaim pass dari sandbox ini:

- `npm run lint` dengan ESLint/Next plugin yang terpasang dari project dependencies.
- `npm run build` production Next.js asli (dan official project `npm run typecheck` setelah install dependency types).
- Visual/browser QA pada aplikasi Next.js yang benar-benar berjalan, termasuk console/hydration check dan service-worker offline simulation end-to-end.

GitHub Actions yang disertakan menjalankan seluruh gate tersebut pada environment yang memiliki npm registry access. Production deployment sebaiknya hanya dipromosikan setelah workflow itu hijau dan browser smoke test berhasil.
